# Security Policy

## Reporting

Please report security, privacy, or credential-exposure issues privately instead of opening a public issue.

Use GitHub's private vulnerability reporting flow when it is available for `yingzhou-bjtu/multipath-delay-measurements`. If that flow is not enabled, contact the maintainer through the public profile contact channel and include a minimal, non-sensitive reproduction.

## Scope

Security reports may include leaked credentials, private paths, unsafe defaults, unexpected network exposure, or data handling problems. Do not include active secrets, private keys, access tokens, or personal data in public issues, pull requests, commits, or logs.
